# Хаттама AI — локальный прототип

Веб-интерфейс для превращения короткой записи совещания в транскрипт, черновик поручений и DOCX. Конфигурация подготовлена для MacBook Air Intel 2017, macOS 12.7.6, Python 3.9.6, 8 ГБ RAM. Полный запуск именно на этом Mac должен быть подтверждён пользователем. Результаты доступной проверки перечислены в VALIDATION.md.

## Быстрый запуск на Mac

1. Распакуйте архив в «Загрузки». Папка должна называться `khattama-ai`.
2. Откройте Терминал и выполните:

```bash
cd ~/Downloads/khattama-ai
bash install_mac.sh
.venv/bin/python prepare_models.py
bash start.sh
```

3. Откройте http://127.0.0.1:8501 .

Установка выполняется в отдельную `.venv`, системный Python не меняется. Для Python 3.9/Intel используется готовая CPU-сборка llama-cpp-python, без Homebrew и компиляции. Интернет нужен для установки пакетов и предварительной загрузки моделей. Аудио и текст при этом не открываются и не отправляются. Для установки, весов и временных файлов оставьте примерно 5 ГБ свободного места.

Команды выполняйте по очереди. Если одна завершилась ошибкой, следующие не запускайте: сохраните последние строки ошибки. Для остановки приложения нажмите Ctrl+C в Терминале. Повторный запуск: `bash start.sh`.

## Первый проход

1. Загрузите «Совещание №2.mp3» как более короткую запись.
2. Выберите русский язык, первые 60 секунд. Число голосов сначала оставьте 0 (авто).
3. После распознавания прослушайте образцы голосов и впишите имена. Проверьте текст; исправьте ошибки.
4. Дату оставьте неизвестной: в предоставленных PDF дата встречи отсутствует.
5. Сформируйте поручения. Сверьте каждое с репликой-основанием и аудиофрагментом.
6. Скачайте DOCX. Если короткая проверка работает, обработайте всю запись.

В PDF каждого примера пять говорящих по ролям. Это не доказывает, что MP3 содержит пять разных голосов: если сценарий озвучил один человек, акустическая диаризация не должна выдумывать пять голосов. При известном реальном числе голосов его можно указать явно.

## Что реализовано

| Требование | Реализация и граница проверки |
|---|---|
| Speech-to-text | faster-whisper small, CPU INT8, временные метки слов |
| Русский / казахский | Режимы `ru` и `kk`; качество нужно измерить на целевых аудио |
| Смешанная речь | Определение языка по 30-секундным окнам; переключение внутри окна может теряться |
| Диаризация | Sherpa-ONNX, сегментация pyannote и NeMo TitaNet Small, локальная кластеризация |
| Привязка к человеку | Пользователь подтверждает имена акустических кластеров; модель извлекает исполнителя по смыслу |
| Поручения / саммари | Локальная Qwen2.5-3B-Instruct Q4_K_M, JSON-схема, ссылки на ID реплик |
| Экспорт | DOCX, JSON и отдельный TXT до формирования поручений |

Модель 3B выбрана ради памяти и скорости старого ноутбука. Ошибки в смысле, именах и сроках ожидаемы; это не промышленная точность. Отсутствующий срок сохраняется пустым. Отсутствующий исполнитель не заменяется автоматически говорящим. День недели без однозначного календарного смысла оставляется для уточнения. Формат итоговых дат — YYYY-MM-DD.

Есть самостоятельный текстовый режим для проверки извлечения поручений. Он явно помечен и не считается демонстрацией ASR или диаризации. Пример `examples/mixed_meeting.txt` создан для тестирования; это не транскрипт предоставленных MP3.

## Архитектура

Streamlit принимает файл в память. PyAV декодирует аудио в mono 16 kHz. Whisper выдаёт слова с временными метками; после выгрузки ASR запускается диаризация. Слова сопоставляются голосам по длительности пересечения. Неоднозначные пересечения помечаются для проверки. Пользователь связывает голос с именем. Qwen получает только текст реплик и список участников, возвращает JSON. Валидатор проверяет ID оснований и осторожно нормализует даты. Пользователь редактирует результат, python-docx формирует документ.

Модели загружаются последовательно, без постоянного удержания всех весов в памяти. Для данной конфигурации установлен предел аудио 10 минут и ограничение входного текста языковой модели; при превышении приложение предлагает разделить запись. Это пакетная обработка, скорость реального времени не заявляется.

## Воспроизводимость

- Основные пакеты закреплены в `requirements.txt`. Для целевого Intel Mac / Python 3.9 установщик использует полный `requirements-mac.lock`; фактически установленное окружение сохраняется в `installed_versions.txt`.
- Ревизии Whisper и Qwen закреплены в `prepare_models.py`.
- Контрольные суммы фактически загруженных моделей сохраняются в `models/manifest.json`.
- Диаризация использует опубликованные авторами ONNX-файлы; их SHA256 фиксируется при загрузке. Для строгого повторения переносите один и тот же каталог `models` и сравнивайте manifest.
- Диагностика: `.venv/bin/python doctor.py`.
- Проверки логики: `.venv/bin/python -m unittest discover -s tests -v`.

В `evaluation/meeting_reference_checks.json` — ручная разметка по двум предоставленным PDF: 10 и 6 строк итоговых таблиц, дополнительное обязательство и неоднозначности. Она не импортируется приложением и не подставляется в ответы модели. Оригинальные PDF/MP3 и полные транскрипты в архив не включены.

Для честной оценки: сначала обработайте аудио, затем сопоставьте поручения с эталоном. Отдельно считайте пропуски, выдуманные задачи, ошибки исполнителя и срока. Для WER и DER нужна выверенная текстовая/временная разметка; она здесь не создана. Сравнение только с итоговой таблицей неполно: у обучения отдельно есть месячный срок. Подготовьте дополнительную казахскую и смешанную запись с несколькими настоящими голосами.

## Приватность и закрытый контур

Приложение слушает только `127.0.0.1`. В коде нет клиента облачного распознавания или внешней LLM. Телеметрия Streamlit/Hugging Face отключена, модели загружаются только с локальных путей в offline-режиме. Запись и текст хранятся в памяти текущего процесса, пока открыта сессия; автоматического сохранения аудио на диск нет. Экспорт сохраняет пользователь через браузер. Кнопка очистки удаляет состояние приложения, но не удаляет уже скачанные файлы и не гарантирует криптографическое стирание RAM/кэша браузера.

После установки можно отключить внешний доступ и повторить обработку. На изолированный сервер необходимо заранее перенести зависимости, веса и исходники. Текущее приложение — однопользовательский прототип без сетевой авторизации, разграничения прав, резервного копирования и политик хранения. Публиковать его в сеть как готовую корпоративную систему нельзя считать завершённым промышленным развёртыванием.

## Что отложено

Zoom/Teams/Meet-бот, live-поток, уведомления, СЭД, голосовая биометрия и PDF-экспорт не реализованы. DOCX закрывает выбранный вариант экспорта. На Mac можно открыть DOCX в совместимом редакторе и сохранить PDF вручную, но это не функция прототипа.

## Ошибки запуска

На Linux установщик собирает llama-cpp-python из исходников: предварительно нужны gcc/g++ и средства сборки. Готовая Linux-сборка 0.3.2 из CPU-индекса в тестовой среде оказалась несовместима с glibc. Это не относится к отдельной сборке для Intel Mac.

- `No matching distribution`: пришлите название пакета и `python3 --version`. Используйте приложенный установщик; не меняйте версии наугад.
- Ошибка скачивания: повторите `prepare_models.py`; уже скачанные веса сохраняются. Можно скачать отдельно `--only asr`, `--only diarization` или `--only llm`.
- При отсутствии интернета новые модели не загрузятся. Уже подготовленные локальные модели работают без внешних API.
- Медленная обработка: начните с 60 секунд и закройте лишние приложения. Это не измерение скорости вашего Mac.
- Мало/много голосов: проверьте реальное число голосов и повторите с ним. Разделение одновременной речи ограничено.
- Некорректный JSON или длинный ответ: попробуйте меньший фрагмент. Приложение не показывает обрезанный JSON как успешный результат.
