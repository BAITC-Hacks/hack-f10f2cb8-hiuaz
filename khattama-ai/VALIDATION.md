# Проверка прототипа

Проверено в Linux x86_64 / Python 3.12, а не на Mac пользователя. Проверка совместимости пакетов выполнена отдельно для CPython 3.9 / macOS 12 x86_64. Ниже отделены фактические запуски от неподтвержденных свойств.

## Что выполнено

- Разрешение зависимостей с `pip --dry-run --ignore-installed --only-binary=:all: --platform macosx_12_0_x86_64 --python-version 3.9 --implementation cp --abi cp39` прошло. Результат закреплен в `requirements-mac.lock`.
- С официального GitHub скачана сборка llama-cpp-python 0.3.2 для CPython 3.9 / Intel Mac. Заголовки Mach-O библиотек указывают минимальную macOS 10.9. Это проверка артефакта сборки, не запуск на Mac.
- Исходники разбираются грамматикой Python 3.9. Скрипты установки/запуска прошли `bash -n`.
- Семь тестов прошли: неизвестная дата встречи, относительные/неоднозначные сроки, точные/ошибочные даты, пересечение голосов, отсутствующий исполнитель и вымышленные ID, DOCX с неопределенными полями, интерфейс и блокировка экспорта после изменения источника.
- Streamlit AppTest: стартовый экран, текстовый режим, импорт реплик, редактирование/экспортная часть на синтетическом результате, инвалидирование результата при изменении даты — без исключений. Подстановка результата в UI-тесте проверяет интерфейс, не качество модели.
- PyAV прочитал «Совещание №2.mp3»: декодированная длительность 206,031 секунды. Отличие от контейнерных 206,064 секунды связано с декодированной аудиодорожкой.
- Whisper small INT8 действительно обработал первые 30 секунд этого MP3: 65 слов, обнаруженный язык ru. Текст не подставлялся из PDF. Оценка WER не выполнялась.
- Sherpa-ONNX действительно обработал первые 60 секунд этого MP3: 10 интервалов, 4 акустических кластера при автоматическом выборе. Это число кластеров модели, не подтвержденное число участников. Оценка DER не выполнялась.
- Локальная Qwen2.5-3B-Instruct Q4_K_M на созданном смешанном текстовом примере выдала 5 поручений: отчет, сравнение предложений, проверка договора Ерланом, смета, завершение обучения. Ссылки соответствуют существующим ID. Дата «завтра» при якоре 23.09.2026 нормализована в 24.09.2026. Недельный срок сметы отделен от месячного срока обучения.

## Найденные ограничения

- В текстовом примере модель назвала задачу «подготовить отчет», хотя исходная реплика требует отправить готовый отчет. Смысл действия необходимо проверять; совпадение количества задач не доказывает точность.
- Более компактная модель 1.5B пропускала задачи и путала исполнителя; она исключена из итоговой конфигурации.
- Для срока без точной даты остаются поля для уточнения. «За месяц» не переводится автоматически в дату, поскольку календарная интерпретация требует подтверждения.
- Qwen 3B использует Research License для исследования/оценки. Это ограничение выбранного демонстрационного набора весов, а не утверждение о готовности к коммерческому внедрению.
- Настройка с подсказкой количества голосов не проверена на полном файле. Имена голосам автоматически не присваиваются: пользователь подтверждает их после прослушивания.
- Качество казахского и смешанного ASR на аудио не проверено. Проверенный смешанный пример — текст, а не аудиотест.
- Полные два совещания через всю цепочку не прогонялись; точность относительно всех строк PDF не измерена.
- Офлайн-пути моделей и настройки предусмотрены, но отдельный запуск в сетевой песочнице с полностью заблокированным исходящим трафиком не выполнялся.
- DOCX проверен повторным открытием и содержимым таблицы. Визуальный просмотр в Word/Pages и проверка верстки длинного полного протокола остаются на целевой системе.
- Скорость и пиковая память на MacBook Air 2017 не измерены. Замеры серверной среды не используются для обещания скорости ноутбука.

## Что проверить до защиты

1. Выполнить установку на целевом Mac, загрузить модели, запустить `doctor.py`.
2. Пройти первые 60 секунд записи, затем полный файл, если позволяет время.
3. Подтвердить имена голосов, сравнить результат с ручной разметкой.
4. Записать короткий казахский и смешанный диалог с разными голосами; проверить ошибки.
5. Открыть экспортированный DOCX, проверить текст, таблицу, сроки и переносы.
6. После загрузки моделей отключить внешний доступ и повторить короткую обработку.

Наличие кода для семи требований не означает, что все семь уже прошли приемку на пользовательском оборудовании.
